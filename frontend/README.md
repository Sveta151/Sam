# Sam Frontend (Next.js)

Minimal Next.js 14 setup for the Sam hackathon project.

## Requirements
- Node.js 18+
- npm, yarn, or pnpm

## Install
```bash
npm install
```

## Develop
```bash
npm run dev
```
App runs at http://localhost:3000

## Build & Start
```bash
npm run build
npm start
```

## Structure
- `app/` App Router
- `styles/` Global styles
- `next.config.mjs` Next.js config
